# Problem: Two Sum (Easy)

**Link:** https://leetcode.com/problems/two-sum/

## Approach

I used a approach with two nested loops. 
For each element, I check the remaining elements to find a pair whose sum is equal to the target.

## Complexity

- Time: O(n²)
- Space: O(1)

## Notes

The solution was tested locally using two test cases before submitting it to LeetCode. The second test case checks duplicate values.
